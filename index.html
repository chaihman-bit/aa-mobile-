Google Cloud Console → APIs & Services → Credentials
จาก URL: docs.google.com/spreadsheets/d/ID/edit
ขั้นตอนตั้งค่า Google Sheets API
  1. ไปที่ console.cloud.google.com → สร้าง Project ใหม่
  2. APIs & Services → Library → ค้นหา "Google Sheets API" → Enable
  3. ค้นหา "Google OAuth2 API" → Enable (สำหรับ user info)
  4. APIs & Services → Credentials → Create Credentials → OAuth 2.0 Client IDs
  5. Application type: Web application
  6. Authorized JavaScript Origins: ใส่ URL ของไฟล์ HTML นี้
    (ถ้าเปิดจาก file:// ให้ใส่ http://localhost หรือ deploy บน web hosting)
  7. Copy Client ID มาวาง
  8. สร้าง Google Sheets ว่าง → Copy ID จาก URL → วางในช่อง Spreadsheet ID
  9. แอปจะสร้าง Sheet ย่อยทั้งหมดให้อัตโนมัติ ✅
💡 Tip: แนะนำให้ deploy ไฟล์นี้บน GitHub Pages หรือ Netlify เพื่อใช้งานได้ง่ายขึ้น
